## How the audit was done
- Fetched `/sitemap.xml` (29 URLs) and `/robots.txt`, then crawled every internal link found on every page (breadth-first). Result: **169 URLs requested**, 162 returned 200.
- Many URLs are duplicates (`/../x`, trailing-slash variants, `index.php`) or 301 redirects. After de-duplication there are **57 unique content pages** (+ 62 blog posts, 1 blog index, 1 PDF).
- Only publicly reachable HTML was inspected. `/admin/` is disallowed by robots.txt and was **not** accessed. The legacy PHP backend (form handler `interactiveform.php`, blog CMS) was not available; behaviour was inferred only from public client-side JS.

## Findings that need the owner's attention
1. **Unverified claims copied from the reference site** (kept as the company's own copy; please verify): HIPAA/GDPR/ISO compliance statements, "50+ AI projects delivered", "95% accuracy", "automating 60% of ticket loads", "lowering overhead by 40%", "up to 40%" wait-time reductions, the "100% IP ownership" guarantee, "Fortune number of companies".
2. **Founding year conflict**: About page says "2008 Year of Establishment"; the homepage JSON-LD says `foundingDate: 2009`. The About text is kept as-is; the JSON-LD was not carried over. Confirm which is right.
3. **Client logos not reproduced**: the homepage "We take on challenging projects" strip shows 12 third-party brand logos (e.g. Barclays). Nothing on the site proves these are clients, so they were deliberately **not** displayed. Provide confirmed client logos + permission and add them via the Media module.
4. **Awards/recognition**: only three review-site profile badges exist (Clutch, GoodFirms, AppFutura). They are shown as links to those profiles — no award claims were added.
5. **"Interactive AI Consultant" on the reference site is not AI**: it is a keyword matcher over five canned paragraphs with a typewriter effect. The rebuild keeps those five verified answers as an honest offline fallback and adds a real server-side LLM endpoint that activates only when `ANTHROPIC_API_KEY` is set.
6. **Terms & Conditions**: the reference site has no such page (only `/privacy-policy/`). No legal text was invented. Provide the text and add it as a page in Admin → Pages (type LEGAL).
7. **Careers**: the reference page has an application form with résumé upload (first/last name, phone, email, summary, .doc/.docx/.pdf). Not rebuilt — see Limitations in README.
8. **Contact form captcha**: the reference form has a custom captcha. Replaced by honeypot + minimum-fill-time + DB-backed rate limiting, with optional Cloudflare Turnstile.
